# Reproduce GENCO §5.1 (Power Flow on PFΔ)

This covers **Figure 4**, **Figure 18**, and **Table 4**.

## 1. Saved results

The GENCO numbers used in the paper are already saved on the following branch, one CSV per task: [scripts/pfdelta/results](https://github.com/gridfm/gridfm-graphkit/tree/genco-paper-repro-pfdelta/scripts/pfdelta/results).

Look at `scripts/pfdelta/results/<task>/metrics_summary.csv` (IEEE 118). **Table 4** (in the paper) is task **3.1**.

PFNet, CANOS-PF, GNS-S, and Newton–Raphson numbers are taken from PFΔ (on the same splits).

To generate the figures and tables from these saved results, jump to [Figures and tables](#6-figures-and-tables).


## 4. Training

Use this graphkit branch and these configs:

- Branch: [genco-paper-repro-pfdelta](https://github.com/gridfm/gridfm-graphkit/tree/genco-paper-repro-pfdelta)
- Configs: [HGNS_PF_pfdelta_bs64_seed1.yaml](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro-pfdelta/scripts/pfdelta/config/HGNS_PF_pfdelta_bs64_seed1.yaml), [HGNS_PF_pfdelta_bs64_seed2.yaml](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro-pfdelta/scripts/pfdelta/config/HGNS_PF_pfdelta_bs64_seed2.yaml), [HGNS_PF_pfdelta_bs64_seed3.yaml](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro-pfdelta/scripts/pfdelta/config/HGNS_PF_pfdelta_bs64_seed3.yaml)

Same YAML for every task; only `--data_path` changes.

```bash
gridfm_graphkit train \
  --config scripts/pfdelta/config/HGNS_PF_pfdelta_bs64_seed1.yaml \
  --data_path pfdelta_task4.3/case118 \
  --exp_name case118_task4.3 \
  --run_name bs64_same_norm_shuffle_train_paper_seed1
```

Repeat for seeds 2 and 3, and for the other `pfdelta_task*` datasets.

## 5. Evaluating the paper checkpoints

You can also reuse our saved models

**Checkpoints:** [gridfm/genco-pfdelta](https://huggingface.co/gridfm/genco-pfdelta)

Weights: `task_<id>/seed{1,2,3}/last.pt`. These match the paper CSVs.

The training runs that match the paper CSVs are in the same repo under [`mlflow/`](https://huggingface.co/gridfm/genco-pfdelta/tree/main/mlflow).

Task 3.1 was not trained separately. The paper 3.1 numbers come from evaluating the **task 1.3 best-validation snapshot** (`best_model_state_dict.epoch_299.pt`) on 3.1 data, not from `last.ckpt`. Those files are under [task_3.1/](https://huggingface.co/gridfm/genco-pfdelta/tree/main/task_3.1) (`seed{1,2,3}/`).

```bash
gridfm_graphkit evaluate \
  --config scripts/pfdelta/config/HGNS_PF_pfdelta_bs64_seed1.yaml \
  --model_path path/to/last.pt \
  --data_path pfdelta_task4.3/case118
```

For task 3.1, use `task_3.1/.../best_model_state_dict.epoch_299.pt` (the 1.3 val-best weights) and `--data_path` pointing at the 3.1 `case118` folder.

## 6. Figures and tables

From the graphkit repo root (`pip install -e .` already pulls in pandas, matplotlib, seaborn). 

Scripts: [make_latex_tables.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro-pfdelta/scripts/pfdelta/make_latex_tables.py), [format_table_exponents.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro-pfdelta/scripts/pfdelta/format_table_exponents.py), [make_pbl_barplots.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro-pfdelta/scripts/pfdelta/make_pbl_barplots.py).

```bash
python scripts/pfdelta/make_latex_tables.py
python scripts/pfdelta/format_table_exponents.py
python scripts/pfdelta/make_pbl_barplots.py --metric mean   # Figure 4
python scripts/pfdelta/make_pbl_barplots.py --metric max    # Figure 18
```

GENCO cells come from `scripts/pfdelta/results/<task>/metrics_summary.csv` (you have to provide it). 

Output:

- `scripts/pfdelta/figures/pbl_all_rows_{mean,max}.pdf`
- `scripts/pfdelta/table_a_{8,9,10,11}_genco_exponent_fixed.tex`

Table 4 is `table_a_10_genco_exponent_fixed.tex` (task 3.1).
