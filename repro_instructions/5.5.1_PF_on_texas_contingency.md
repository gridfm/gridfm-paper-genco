# Reproduce GENCO §5.5.1 (topology perturbations)

Bus-level relative active power-balance residuals on the Texas 2000-bus system for N-1 through N-20. GENCO Base is trained only on N-2. DC-PF is the baseline. Section 5.5.2 uses the same checkpoint on the N-2 test set.

## 1. Saved results

The paper numbers are already saved in [relative_residual_summary_by_k.csv](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/contingency/results/relative_residual_summary_by_k.csv). It has one row per contingency order.

To generate the figures and tables from these saved results, jump to [Figures and tables](#6-figures-and-tables).

## 2. Data

The 20 eval runs are in [gridfm/genco-pf-contingency](https://huggingface.co/gridfm/genco-pf-contingency) under [mlflow/eval/](https://huggingface.co/gridfm/genco-pf-contingency/tree/main/mlflow/eval) (`test_<k>/`: `meta.yaml`, `predictions.parquet`, and `dc_bus_residuals.parquet`).

```bash
hf download gridfm/genco-pf-contingency --include "mlflow/eval/**" --local-dir genco-pf-contingency
```

The training grid and each `test_<k>` grid are in the same repo as raw parquet only, at `data/<split>/Texas2k_case1_2016summerpeak/raw/`. There is no `processed/` directory.

```bash
hf download gridfm/genco-pf-contingency --include "data/training_dataset/**" --local-dir genco-pf-contingency
hf download gridfm/genco-pf-contingency --include "data/test_1/**" --local-dir genco-pf-contingency
```



## 3. Install

```bash
git clone -b genco-paper-repro https://github.com/gridfm/gridfm-graphkit.git
cd gridfm-graphkit
pip install -e .
TORCH_CUDA_VERSION=$(python -c "import torch; print(torch.__version__ + ('+cpu' if torch.version.cuda is None else ''))")
pip install torch-scatter -f https://data.pyg.org/whl/torch-${TORCH_CUDA_VERSION}.html
export MLFLOW_ALLOW_FILE_STORE=true
```

Run the later commands from that repository root.

## 4. Training

Branch [genco-paper-repro](https://github.com/gridfm/gridfm-graphkit/tree/genco-paper-repro). Train config [caseTexas_train.yaml](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/contingency/configs/caseTexas_train.yaml): hidden size 48, seed 0, 200 epochs, batch size 4.

```bash
gridfm_graphkit train \
  --config scripts/contingency/configs/caseTexas_train.yaml \
  --data_path genco-pf-contingency/data/training_dataset
```

## 5. Evaluating the paper checkpoints

You can also reuse our saved models

**Checkpoints:** [model/training_bs_16/](https://huggingface.co/gridfm/genco-pf-contingency/tree/main/model/training_bs_16)

Weights: `best_model_state_dict.pt` and `normalizer_stats.pt`. Training MLflow params are under [`mlflow/train/training_bs_16/`](https://huggingface.co/gridfm/genco-pf-contingency/tree/main/mlflow/train/training_bs_16).

```bash
hf download gridfm/genco-pf-contingency --include "model/**" --local-dir genco-pf-contingency
```

Use [caseTexas_eval.yaml](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/contingency/configs/caseTexas_eval.yaml) (`test_ratio` 0.99, batch size 256). Pass `--compute_dc_ac_metrics` and `--save_output` so the plot script can read the predictions and the DC residuals.

```bash
gridfm_graphkit evaluate \
  --config scripts/contingency/configs/caseTexas_eval.yaml \
  --data_path genco-pf-contingency/data/test_2 \
  --model_path genco-pf-contingency/model/training_bs_16/best_model_state_dict.pt \
  --normalizer_stats genco-pf-contingency/model/training_bs_16/normalizer_stats.pt \
  --compute_dc_ac_metrics \
  --save_output
```

Repeat for `test_1` through `test_20`. The published figures use the predictions already in [mlflow/eval/](https://huggingface.co/gridfm/genco-pf-contingency/tree/main/mlflow/eval).

## 6. Figures and tables

[n-k_contingency_plots_relative.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/contingency/n-k_contingency_plots_relative.py) reads each `test_<k>` folder.

```bash
python scripts/contingency/n-k_contingency_plots_relative.py \
  --mlflow-dir genco-pf-contingency/mlflow/eval \
  --output-dir figures
```

It writes `boxplot_relative_residuals.png`, `boxplot_zero_inj_absolute_residuals.png`, `threshold_share_relative_k10.pdf`, `threshold_share_absolute_k10.pdf`, `threshold_share_absolute_k10_zero_inj.pdf`, `below_1pct_threshold_vs_k.pdf`, and `relative_residual_summary_by_k.csv`.
