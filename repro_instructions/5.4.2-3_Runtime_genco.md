# Reproducing the GENCO paper (GPU runtime)

PF inference timings for the [GENCO paper](https://arxiv.org/abs/2608.09921). The OPF GENCO curves use these same PF timings. There is no separate OPF GENCO benchmark (because the model etc is the same, only the data changes, but the data does not have an impact on the runtime). 

Residual and optimality numbers are in [5.4.2_PF_on_datakit](5.4.2_PF_on_datakit.md) and [5.4.3_OPF_on_datakit](5.4.3_OPF_on_datakit.md).

There are two protocols, as in [5.4.2-3_Runtime_powermodels](5.4.2-3_Runtime_powermodels.md). **In-memory** preloads the graphs and times inference only. **From-disk** loads each graph inside the timed work. Both read processed graphs, not a trained checkpoint. The model is built at the config hidden size (tiny 12 / small 24 / base 48) with a random `baseMVA`. Wall time does not depend on the paper weights.

## 1. Saved results

The GPU timings used in the paper are already saved on [genco-paper-repro](https://github.com/gridfm/gridfm-graphkit/tree/genco-paper-repro/scripts/runtime).

`genco_pf_in_memory/` is the in-memory sweep. `genco_pf_from_disk/` is the from-disk sweep. The metric used in the paper is `outer_elapsed_ms / num_samples`. The best batch size corresponds to when this metric is minimized. Rows with `status` other than `ok` are omitted (e.g. out of memory).

## 2. Data

```text
$GENCO_DATA_PATH/<network>/processed/data_index_*.pt
```

The first 10,000 `data_index_*.pt` files per network are on Hugging Face as one tar per grid: [gridfm/genco-pf-runtime](https://huggingface.co/datasets/gridfm/genco-pf-runtime).

```bash
hf download gridfm/genco-pf-runtime --repo-type dataset \
    --local-dir /path/to/pf
for t in /path/to/pf/*.tar; do tar -xf "$t" -C /path/to/pf; done
export GENCO_DATA_PATH=/path/to/pf
```

Each `<network>.tar` contains `<network>/processed/data_index_0.pt` through `data_index_9999.pt`. The dataset has IEEE 14, 30, 57, 118 and GOC 500, 2000, and 10000.

In-memory runs preload those 10,000 graphs. From-disk runs copy them to node-local `/tmp` (because our GPFS storage is slower) and load each file inside `Dataset.get()`.

## 3. Install

```bash
git clone -b genco-paper-repro https://github.com/gridfm/gridfm-graphkit.git
git clone -b genco-paper-repro https://github.com/gridfm/gridfm-datakit.git
cd gridfm-graphkit
pip install -e .
TORCH_CUDA_VERSION=$(python -c "import torch; print(torch.__version__ + ('+cpu' if torch.version.cuda is None else ''))")
pip install torch-scatter -f https://data.pyg.org/whl/torch-${TORCH_CUDA_VERSION}.html
export MLFLOW_ALLOW_FILE_STORE=true
```

Clone the two repos next to each other. A rerun needs a GPU. Rebuilding the figures does not. Paper jobs used Python 3.12.9, PyTorch 2.8.0+cu128, and CUDA 12.8. The dump of that environment is [environment_versions.md](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/outputs_genco/environment_versions.md) on the graphkit branch.

## 4. Evaluating the paper checkpoints

There is no saved checkpoint to evaluate. This step re-runs the timing sweeps on the processed graphs.

Optional. The committed CSVs are the paper numbers, but you can also re-run the runtime evaluation.

**In-memory** preloads the 10,000 graphs, then times batched inference. IEEE batches start at 64. GOC batches start at 16. [run_pf_in_memory_ieee.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/run_pf_in_memory_ieee.py) and [run_pf_in_memory_goc.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/run_pf_in_memory_goc.py).

```bash
python scripts/runtime/run_pf_in_memory_ieee.py --data-path "$GENCO_DATA_PATH"
python scripts/runtime/run_pf_in_memory_goc.py --data-path "$GENCO_DATA_PATH"
```

**From-disk** copies those graphs to node-local `/tmp` and loads each one inside `Dataset.get()`, so loading is part of the timed work. Same batch lists as in-memory. [run_pf_from_disk_ieee.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/run_pf_from_disk_ieee.py) and [run_pf_from_disk_goc.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/run_pf_from_disk_goc.py).

```bash
python scripts/runtime/run_pf_from_disk_ieee.py --data-path "$GENCO_DATA_PATH"
python scripts/runtime/run_pf_from_disk_goc.py --data-path "$GENCO_DATA_PATH"
```

On LSF, [submit_pf_matrix.sh](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/submit_pf_matrix.sh) submits those four scripts (1 exclusive H100, 128G, 40 slots, as used for the paper).

## 5. Figures and tables

Set `POWERMODELS_MATRIX_ROOT` to the datakit `full_matrix` directory if the datakit clone is not beside this repo. From the graphkit repo. Scripts: [plot_runtime_comparison_from_raw_pf.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/plot_runtime_comparison_from_raw_pf.py), [plot_runtime_comparison_from_raw_opf.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/plot_runtime_comparison_from_raw_opf.py), [plot_pf_opf_benchmark_matrix_appendix.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/plot_pf_opf_benchmark_matrix_appendix.py), [plot_juliacall_scaling_comparison.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/plot_juliacall_scaling_comparison.py), [plot_loading_overhead_best_config.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/plot_loading_overhead_best_config.py), [build_pf_tradeoff_table.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/build_pf_tradeoff_table.py), [build_opf_tradeoff_table.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/build_opf_tradeoff_table.py), [build_loading_speedups_table.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/build_loading_speedups_table.py).

```bash
export POWERMODELS_MATRIX_ROOT=../gridfm-datakit/scripts/runtime/outputs_julia/full_matrix
mkdir -p figures

python scripts/runtime/plot_runtime_comparison_from_raw_pf.py --output figures/runtime_comparison_from_raw_pf.pdf
python scripts/runtime/plot_runtime_comparison_from_raw_opf.py --output figures/runtime_comparison_from_raw_opf.pdf
python scripts/runtime/plot_pf_opf_benchmark_matrix_appendix.py --output figures/pf_opf_benchmark_matrix_appendix.pdf
python scripts/runtime/plot_juliacall_scaling_comparison.py --output figures/juliacall_scaling_comparison.pdf
python scripts/runtime/plot_loading_overhead_best_config.py --output figures/loading_overhead_best_config.pdf

python scripts/runtime/build_pf_tradeoff_table.py
python scripts/runtime/build_opf_tradeoff_table.py --model small
python scripts/runtime/build_loading_speedups_table.py
```

[plot_runtime_comparison_from_raw_opf.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/plot_runtime_comparison_from_raw_opf.py) reads the PF GENCO CSVs and the PowerModels OPF curves. [build_opf_tradeoff_table.py](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/build_opf_tradeoff_table.py) uses those same GENCO times for the speedup columns and `scripts/datakit_opf/results/opf_scaling_aggregated.csv` for the gap and violation columns.

## Notes

- Hidden size is 12 / 24 / 48 for tiny / small / base. Compile mode is `reduce-overhead`, with 20 warmup batches and 32 loader workers.
- Paper environment: Python 3.12.9, PyTorch 2.8.0+cu128, CUDA 12.8, one H100 80GB. Details: [environment_versions.md](https://github.com/gridfm/gridfm-graphkit/blob/genco-paper-repro/scripts/runtime/outputs_genco/environment_versions.md).
